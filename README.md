# Regularization Path Explorer

Interactive Week 6 teaching tool for ANLY 530: Principles & Applications of Machine Learning.

## Concepts
Ridge, Lasso, Elastic Net, regularization strength, coefficient paths, training/validation behavior, correlated predictors, sparsity, and leakage-safe pipelines.

**Teaching note:** The numerical coefficient paths and performance curves are illustrative simulations for conceptual learning, not empirical model results.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, and `app.js` to a repository. Enable GitHub Pages from the `main` branch/root.
