# Regularization Path Explorer — Version 2

Interactive Week 6 teaching tool for ANLY 530.

## Version 2
- Fixes the JavaScript initialization error.
- Shows current coefficient values and retained/zero status.
- Adds a live “What Changed and Why?” interpretation panel.
- Adds an interactive fold-by-fold pipeline walkthrough.
- Lets students compare `transform()` with leakage-causing `fit_transform()` on a validation fold.

**Teaching note:** Numerical coefficient paths and performance curves are illustrative simulations for conceptual learning, not empirical results.

Replace the repository files with these files; GitHub Pages will update automatically from the configured branch.
